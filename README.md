# Personal Portfolio Website

Personal portfolio website of **Olga Kabsyah Ramadhani**, a Data Science Technology graduate from Universitas Airlangga, showcasing projects, professional experience, technical skills, and achievements.

**Live Website:** https://kabsyahr.github.io/

## Overview

This website serves as a central platform for presenting my work in Data Analytics, Business Intelligence, Machine Learning, and Natural Language Processing.

The portfolio includes:

- **Featured Projects:** Selected projects highlighting analytical methods, technical implementation, and business insights.
- **All Projects:** Additional projects automatically retrieved from public GitHub repositories.
- **Professional Experience:** Internship experience and relevant responsibilities.
- **Technical Skills:** Programming languages, analytical tools, and technologies.
- **Achievements:** Academic recognition, certifications, and professional development.
- **Contact:** Links to professional profiles and communication channels.
